## Features

- Tasks anywhere in your vault!
- Automatic day planning
- Sub-tasks
- Today & week view
- Quick filters
- Top task priority (shown in the Status Bar)
- Status tracking
- Status customization
- Seamless Streams Plugin integration

## Installation

1. Open Obsidian and go to **Settings** -> **Community plugins**.
2. Turn off "Safe mode" if it is currently enabled.
3. Click **Browse** and search for "OnTask".
4. Click **Install**.
5. Once installed, click **Enable** to turn on the plugin.

## Basic Usage

1. Open the command palette (`Ctrl/Cmd + P`) and search for **OnTask: Open View** to open the main task dashboard.
2. In any markdown file, simply create standard markdown checkboxes within your daily note (e.g. `- [ ] My new task`). OnTask will automatically find them and aggregate them into your dashboard.
3. Use the OnTask settings panel (**Settings** -> **OnTask**) to customize status symbols, configure quick filters, and manage your active top task.
